# AdsLens

Application web propriétaire (tous droits réservés, pas de licence open source).

Stack : Vite + React + TypeScript + Tailwind CSS + React Router + PapaParse.
Aucun backend, aucune base de données, aucun appel réseau sortant : tout le
parsing et l'analyse CSV se font localement dans le navigateur. C'est une
contrainte produit centrale (RGPD) — ne jamais introduire d'appel réseau,
de télémétrie, ou d'envoi de données vers un service tiers.

Voir `README.md` pour l'installation, les scripts et le déploiement Netlify.
